# PLP Python Week 3 Assignment

This repository contains my Week 3 Python programming assignment.

## Files

- `name_greeter.py` — Splits a user's full name and greets them by their first name.
- `bug_hunt.py` — Fixes three bugs and demonstrates debugging with error messages.
- `ticket_checker.py` — Checks whether a person is an adult and displays the correct ticket price.
- `screenshots/` — Contains screenshots showing the programs running.

## Part B: Bug Hunt Reflection

The bug that took me longest to find was the age calculation bug. The error message helped me understand that Python could not add a number to a string, so I needed to convert the age from a string to an integer using `int()`. Reading the error message carefully helped me identify what needed to be fixed.
